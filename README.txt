ТІЛЕК КУХАЕВ — ЖЕКЕ САЙТ
Жаңартылған дизайн, 6 бет, телефонға және ноутбукке бейімделген.

АШУ
1. ZIP архивін толық шығарыңыз.
2. tilek-site қалтасындағы index.html файлын браузерде ашыңыз.
3. Беттер арасында жоғарғы мәзір арқылы ауысыңыз.
Интернет қосылымы қажет емес. Файлдарды бірге сақтаңыз.

ТЕЛЕФОНДА
Сайттың орналасуы экранға бейімделеді. Мәзір жоғарғы жақтағы екі сызық белгісімен ашылады.
Жүктелген файлды телефонның файл шолғышы JavaScript-сыз алдын ала көрсетуі мүмкін.
Толық жұмыс үшін HTML-ді браузерде ашыңыз немесе статикалық хостингке жүктеңіз.

МҮМКІНДІКТЕР
— Классикалық портрет және суреттердің баяу қозғалысы.
— Бөлімдердің экранға жұмсақ пайда болуы.
— Қозғалысты өшіру/қосу батырмасы. Жүйедегі қозғалысты азайту параметрі ескеріледі.
— Суреттер галереясы: басып үлкейту, келесі/алдыңғы сурет, пернетақтадағы ← → және Esc.
— Python мысалының алдын ала дайындалған нәтижесін көрсету (Python интерпретаторы емес).
— CPU / GPU / RAM ақпараттық қойындылары.

ӨЗГЕРТУ
Мәтін — HTML файлдарында. Дизайн — style.css. Әрекеттер — script.js.
Суреттер — assets қалтасында. Сыртқы кітапханалар мен сервистер қажет емес.
Сайт интернетте жарияланбаған; жариялау үшін қалта мазмұнын статикалық хостингке жүктеуге болады.

СУРЕТТЕР
assets/portrait.webp — пайдаланушы жіберген классикалық портрет.
assets/technology.webp — imagegen арқылы жасалған технологиялық иллюстрация.
Тапсырма: ашық фонда, жасыл тұғыр үстінде видеокарта, процессор, ойын контроллері және ноутбук; логотип пен мәтінсіз табиғи студиялық бейне.
assets/checkers.svg — кодпен салынған дойбы тақтасы.

СОҢҒЫ ӨЗГЕРІС
Галереяға жеке фотосуреттер қосылды. Алдағы оқу мақсаттары мен үйренгім келетін нәрселер туралы бөлімдер алынып тасталды.
